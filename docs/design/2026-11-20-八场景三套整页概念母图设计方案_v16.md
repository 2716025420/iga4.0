## 一、三套整体概念方向定位（A / B / C 对比维度）

本次重构涵盖 **6 大项共 8 处场景**（学生宿舍、校园商店、教学楼天台、沿海公路、旧公园、阿瑞忒海滩、图书馆、体育馆），每处生成 **3 套整页概念母图（`2340×1080` 宽屏整图，不要求透明分层）**：

| 方案代号 | 美术方向定位 | 镜头与构图特色 | 适用选型倾向 |
| --- | --- | --- | --- |
| **Set A** | **清透日光 · 舒展纵深** | 明快通透的广角平视空间，色面简洁干净，视野开阔留白足 | 追求高日常耐看度、UI 与人物叠加零压力 |
| **Set B** | **电影透视 · 光影冲击** | 强化景深纵深、挑高仰/俯角、强光影切割与冷暖大块面反差 | 追求第一眼视觉冲击力、剧场版动画质感 |
| **Set C** | **海滨青春 · 诗意叙事** | 侧重空气感、斜阳/海风光尘、温柔情绪氛围与阿瑞忒学园地域记忆点 | 追求故事代入感、恋爱/悬疑伏笔氛围张力 |

## 四、后续两阶段衔接（挑选定稿后执行）

1. **挑选定稿**：主创从每处场景的 Set A / Set B / Set C 中各自选出最满意的 **1 张整页概念母图**（也可指定“保留某套构图 + 微调某部分色调”）。
2. **阶段二拆分与实装**：选定母图归档至 `docs/concepts/v16/` 后，再针对定稿图做高精度透明分层拆分（`Layer0_Sky` / `Layer1_Midground` / `Layer3_Foreground` 遮挡物）并按 `SceneStageLayers` 与 `SceneDesignCatalog` 替换实装入游戏，确保立绘自然融入且保留全部现有交互体验。
