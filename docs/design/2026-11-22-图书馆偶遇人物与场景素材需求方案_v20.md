## 一、剧本审读与现行素材盘点结论

### 1.1 剧本核心事件与连续性发现
[school_affairs.md](../story/user_write/school_affairs.md) 共包含 4 段连续分镜（34 行正文），全部发生在**从社团教室前往图书馆的清晨海风林荫小路**上：
1. **叶舟晨风独白**：清晨海风吹散睡意，叶舟下定决心去图书馆提升实力；
2. **败北小混混二重唱**：此前被教训的小混混老大（恍惚→燃志）与小混混（哭泣→抹泪崇拜）输光所有卡牌后沿路喊着「欧呜~啦！」撤场；
3. **路人剪影吐槽避让**：`旁白: 路人让开了路` 自动清场后，`路人剪影男`（站左）与 `路人剪影女`（站右）低声议论避让；
4. **图书馆偶遇黄秋枫**：叶舟在 `黄秋枫(惊讶)` 的招呼下与她重逢，两人聊起预选赛队友与图书馆资料，最终约定「两个人一起找资料比一个人成功率高」，`旁白: 两人去图书馆。` 收尾。

### 3.1 导入替换现行临时 `school_affairs` 时的逐句标注参考
待素材交付并审核落位后，将 [school_affairs.md](../story/user_write/school_affairs.md) 导入 `PhaseTwoContent.SCRIPTS["school_affairs"]` 时，按以下最小标注即可与引擎「旁白自动清场 + 左→右重置」状态机完美对齐：

1. 开场独白：`旁白: 清晨的水润……` → 自动清场 → `叶舟: 之前的失败……`（左）→ `叶舟(微笑): 首先去图书馆……`
2. 混混登场：显式标 `小混混老大(恍惚, 右)`（`dazed`，右侧）→ `小混混(担忧, 右)` 或切左右对位 → `小混混(哭泣, 左)`（`crying`）→ `小混混老大(燃志, 右)`（`rally`，挺胸宣言）→ `小混混(抹泪, 左)`（`moved`，`超帅的老大~`）→ `小混混老大(微笑, 右)`（`欧呜~啦！`）→ `小混混(微笑, 左)`（`欧呜~啦！`）
3. 路人避让：`旁白: 路人让开了路` → **引擎自动清空混混立绘并重置左右槽** → `路人剪影男(担忧): 好可怕。。。`（自动站左）→ `路人剪影女(担忧): 好恶心。。。`（自动站右）
4. 叶舟与秋枫重逢：可通过 `[清场]` 或再加过渡旁白 / 显式清场让路人退场，随后 `叶舟(惊讶)` 站左、`黄秋枫(惊讶)` 站右 → 两人自然左右对谈至 `黄秋枫(害羞)` → `叶舟(微笑)` → `旁白: 两人去图书馆。`（可配 P1 `cutscene_ch1_library_walk` 视差过场）。

### 3.2 「从社团去图书馆时触发」代码接线建议（替换临时剧情阶段实施）
当用户正式将这一幕接入可玩主线时，对应备注 `[备注: 这里要从社团去图书馆时触发]` 的推荐接法为：
- 在 `CampusLife.travel_to("library")`（[campus_life.gd](../../scripts/campus/campus_life.gd)）或地图/家园跳转处判断：若 `current_location == "club"` 且 `GameState.next_phase_two_node() == "n_affairs"` 且 `PlayerJourney.act1_story_ready()`（并尚未完成 `school_affairs_done`），在切换到图书馆前自动调用 `GameState.trigger_scene_story("n_affairs")`；
- 在 `GameState.complete_phase_two_step("n_affairs")`（[game_state.gd](../../scripts/global/game_state.gd) 第 756 行）中，现已设计为完成后自动 `CampusLife.travel_to("library")`，与本幕结尾「`旁白: 两人去图书馆。`」无缝衔接！
- **重要剧情衔接提醒**：由于新版 `school_affairs.md` 聚焦于「路上偶遇混混与黄秋枫相约去图书馆」，原临时稿中姜梓提示「校外限幅器告警 + 约傍晚去旧公园」的过场过渡需在图书馆后续事件或新增衔接台词中保留，以免 `n_dusk`（旧公园之约）失去前情引导。
