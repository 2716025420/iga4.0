## 一、核心组合逻辑（为什么这样拆分就能又饱满又不乱）

1. **三层互补填满画面焦点**：
   - **环境概念底（v16/v17 带氛围背景）**：负责定光影情绪与空间纵深；
   - **场景专属人物立绘（v17 模块 1）**：让角色自带环境光影染与动作姿态（不再是无光照感的僵硬正面站桩），作为画面第一视觉焦点；
   - **场景 UI 套件（v17 模块 2）**：保留现有 `SceneHUDLayout` 布局结构（左上 `PeriodDial` + 左侧停靠栏 + 右上资源胶囊 + 行动按钮 + 头顶轻气泡 + 底部手帐对话框/双栏面板），提供 3 套不同质感的边框与玻璃/纸面/木纹样式供您自由搭配！
2. **双路线并行（模块 3 提供“带人整页概念母图”）**：
   - 除了分别生成「场景人物立绘 × 3 套」与「UI × 3 套」进行组合，需求包内还额外准备了 **「带驻场人物焦点的 8 场景整页概念提示词（× 3 套）」**，方便生图时直接把人物参照图和场景融合到同一张整页概念图中比选效果，不再感到画面空洞！

### 2. 场景 UI 套件（保留现有结构 × 3 套材质与质感风格）
