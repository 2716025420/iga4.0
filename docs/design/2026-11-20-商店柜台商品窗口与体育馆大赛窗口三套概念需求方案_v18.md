# 商店柜台商品窗口与体育馆大赛窗口三套概念需求方案（v18）

> **关联规则**：遵循 `AGENTS.md` 「整页概念母图 → 分层还原」强制流程，并与现有 v17 UI Set A（`assets/ui_core/v17_ui_a/` 晴空日系手账 + 玻璃质感胶囊）及 `1920×1080` 逻辑画布保持一致。
> **工作流**：
> 1. **第一阶段（选款）**：先按本方案生成 **商店柜台商品窗口（A/B/C 三套）** 与 **体育馆大赛窗口（A/B/C 三套）**，共 **6 张 `1920×1080` 整页概念母图**（含完整界面文字、图标占位与当前背景同屏融合），由主创选定其中各 1 套。
> 2. **第二阶段（拆层）**：仅针对中选方案拆出透明 PNG 九宫格切片/框体与角标底图（**严禁烘焙中文静态字、商品图标、价格数字或角色头像**），再回接至 Godot `CampusShopPanel` 与 `CampusScreen._open_qualifier_modal()`。

---

## 一、设计目标与当前痛点

对照 `test_artifacts/captures_1600x900/captures/09_shop_counter.png` 与 `10_gym_qualifier.png`：
1. **商店柜台商品窗口（`CampusShopPanel`）**：目前右半屏唐小满（`+150px` 偏右）与 `ClerkSpeechBubble` / `BalanceBacking` 已与明亮海岸小卖部融合得很好，但左半屏 `ProductsBoard (28,22,976,1036)` 仍复用通用旧纸卡 `paper_modal_9slice`，缺少货架分层质感、选中高亮、已拥有角标以及与右侧柜台视觉语言的统一。
2. **体育馆大赛窗口（`QualifierModal`）**：位于蓝色挑高体育馆舞台前方正中 `Rect2(240,130,1440,820)`，目前整张面板和三张赛程横卡同样使用偏素淡旧纸块，缺少「阿瑞忒巡回代表选拔赛」的赛事层次、通关状态区分（可登台 / 已通关 / 待解锁）以及通行章荣耀期待感。

## 三、体育馆代表选拔赛窗口（`QualifierModal` · `1920×1080` 基准）

### 精确布局骨架（概念图与程序共用定尺）
- **背后舞台**：`16_gym_stage` 蓝色玻璃钢构海景体育馆大厅 + 透明深蓝微醺遮罩 `Color(0.12, 0.16, 0.25, 0.56)`。
- **居中赛事主弹窗 `QualifierModal`**：`Rect2(240, 130, 1440, 820)`
  - 顶栏标题 `QualifierTitle` (`44,28,720,50`) + 副标题 `QualifierSub` (`44,80,960,32`)
  - 顶栏右上操作：全胜后出现的 `AtlasPreviewButton`「巡回总图 →」 (`1044,30,194,56`)、常驻 `CloseButton`「返回 ×」 (`1254,30,148,56`)
  - **左栏玩家出战状态卡 `QualifierLeftCol`**：`Rect2(40, 126, 404, 656)`
    - 头像 `PlayerAvatar` (`26,24,108,108`) + 姓名/代表进度/非致命护盾裁决规则
    - 卡匣概况 `DeckCap` (`5/5`)、随行协战（杨子英等）、星座共鸣槽（白羊座）
    - 底部按钮 `GotoWorkshopBtn`「整备行动卡匣 →」 (`26,566,352,62`)
  - **右栏 3 轮赛程卡片 `RoundRow_1..3`**：纵向 3 张等距横卡，`Rect2(464, 126 + i*224, 936, 206)`（`i = 0,1,2`）
    - 左侧对手立绘窗 `EnemyFrame` (`18,18,154,170`)
    - 中部标题 `Title` (`192,20,480,40`) + 说明 `Sub` (`192,66,490,56`) + 奖励与状态 `Reward` (`192,138,500,44`)
    - 右侧挑战钮 `Challenge_1..3` (`704,68,208,70`)：三种状态分别对应 **第 1 轮当前可挑战（朱红强调）**、**已完成（青绿再战）**、**未解锁（柔灰锁定）**。
