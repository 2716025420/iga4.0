## 一、现状病灶诊断（为什么目前看着“散、飘、脏、割裂”）

对照现有实机素材与代码（`scene_object_view.gd`、`scene_design_catalog.gd`、`campus_dialogue_ui.gd`、`campus_screen.gd`），核心症结归纳为 5 条：

1. **生产流程倒置（先直出整图，再硬抠热区）**：现行 5 处背景均是一整张高噪点“伪写实整图”（如 `rooftop.png` 墙面斑驳锈迹、`shop.png` 满柜高细节写实零食、`library.png` 左下特写巨书占半屏），没有事先给**路径、前景遮挡物、NPC 站位、主线演出位与 UI 控件**留出干净构图区。
2. **NPC 贴图无遮挡、无透视、无光影融合**：`SceneObjectView._build_resident_actors()` 把 `2:3` 赛璐璐半身/全身立绘直接贴在写实背景正上方（单一平面 `z_index=-1`），商店没有前景柜台压住唐小满腰部、图书馆没有前景借书台压住林知夏、也未给黄秋枫预留窗边专属位，导致“剪纸悬浮感”极强。
3. **UI 体系在 4 套风格之间打架**：
   - 场景顶栏与悬浮热点还在用旧版撕边米纸贴片（`campus_surfaces.png`）；
   - 地图已升级为 `DynamicUI` 清爽厚涂胶囊 + 水彩叶签；
   - `old_park` 因无多边形热点回退到巨大左下 `PlaceContext` 面板；
   - `library` 主线按钮硬钉在 `y=872`，`dorm` 又用另一套底栏。
4. **场景交互被硬切在“点碎片贴纸”上**：玩家进入场景后，功能按钮散落在画面各处，既遮挡构图又无法一眼区分「免费交谈 / 消耗1活动点 / 主线推进 / 子地点移动」。
5. **容易被忽略但非常致命的隐性体验漏洞（补充审核项）**：
   - **隐性 Bug**：`CampusDialogueUI`（`campus_dialogue_ui.gd` 第 24 行）把 `SpeakerPortrait` 写死了 `.hide()`，导致 `campus_screen.gd` 里精心加载的林知夏/唐小满/同伴头像在场景交谈时**根本没显示**，且与主线 `DialogueScreen` 外观完全割裂；
   - **昼夜光照脱节**：`DayCycle` 有早晨/下午/夜晚三时段，阿瑞忒地图已有昼夜双图，但 5 处功能场景只有单一正午图，夜晚进天台/沿海公路依然是刺眼大晴天；
   - **宽屏（20:9 `2340×1080`）安全区未前置约束**：先前先画 `16:9` 再外扩导致边缘拉伸，新流程应在**线稿布局阶段直接按 `2340×1080` 画宽底、交互锚定在中央 `1920×1080` 安全框内**；
   - **“主线 NPC 在场”与“日常常驻 NPC”缺乏统一槽位协议**：图书馆同时出现林知夏（常驻）+ 黄秋枫（主线），沿海公路/旧公园/体育馆后续也会临时刷出主线 NPC，必须每个场景预设 **Slot A（常驻功能 NPC 位）** 与 **Slot B（主线/同伴剧情位）**，互不打架；
   - **场景内缺少“资源/剩余活动点”常驻可视**：玩家在商店想看零用钱、在图书馆想看还剩几次活动点，目前必须看底栏小字或进弹窗才知道。

## 二、核心重构方法论：从「直出整图抠热区」转为「布局先导 + 五层模块化拼装」

以后所有待重置场景及后续第 2–5 章新场景，彻底废除“直接 AI 生成一整张高写实房间再手动描多边形”的做法，改为 **先定灰度空间蓝图（Wireframe） → 再分 5 层生成/制作素材 → 引擎实时合成**：

```text
Layer 0｜天空与远景层（2340×1080）   ← 独立天空/海面/远景，只需换图或叠加 Shader 色调即可实现 晨/午/昏/红月夜 四时段！
Layer 1｜中景建筑与地坪路径层        ← 干净赛璐璐架构、明确地面透视线、预留 Slot A/B 站位与子地点岔路出口
Layer 2｜NPC 角色层（动态挂载）       ← 严格对齐地坪线/柜台高度 + 统一脚底柔影 + 自动叠加当前时段环境色温微染
Layer 3｜前景遮挡层（真透明 PNG）     ← 商店前台台面 / 图书馆借书台前沿 / 天台护栏桌面 / 体育馆擂台护栏
                                        ※ 这是消除“立绘悬浮感”的灵魂层：把人物腰部以下自然藏进场景空间！
Layer 4｜场景极简空间锚点 + 统一 HUD  ← 告别乱飞的大白纸条！改用“画面内极简定位泡 + 统一停靠交互栏”
```

### NPC 交互与场景融合的两种统一模式（告别突兀大贴纸）
- **模式 A｜柜台近景融合（用于「校园商店」「图书馆借书台」）**：参考 `Angel 24`（`01_场景画风与空间构图/03_商店_正面平视柜台分层_Angel24.webp`）与 `Potionomics`（`03_交互窗口与商店选拔赛/01_商店左货架详情与右店员同屏融合_Potionomics.jpg`）。NPC 位于 Layer 2，前台木柜台位于 Layer 3 遮住下半身；NPC 头顶只挂一枚**极简轻呼吸气泡/名签**，点击或从右侧功能栏进入交互时，NPC 实时切换微笑/倾听表情，直接弹出统一交互栏或商店货架（商店货架居左、唐小满留在右侧实时互动！）。
- **模式 B｜空间站位 + 右侧抽屉式交互（用于「天台」「体育馆」「沿海公路/海滩/旧公园」）**：参考《火山的女儿》（`02_UI控件与HUD布局/02_户外场景NPC点击右侧抽屉菜单_火山的女儿.jpg`）与《P3R》（`02_UI控件与HUD布局/04_NPC头顶极简对话泡与角落定位HUD_P3R.jpg`）。角色按真实远近比例自然站在/靠在场景地坪或护栏旁（配软投影与微呼吸动效），头顶仅浮现精致小气泡（主线人物显示珊瑚红 `✦` 标记）；点击后右侧滑出**立绘半身像+好感+快捷交互清单**（交谈 / 主线剧情 / 一起复盘 / 挑战）。

## 四、五处待重置场景逐一蓝图（功能定位 + 空间布局 + NPC 融合方案）

### 1. 教学楼天台（`rooftop`）
- **重塑功能定位**（解决“定位不清晰”）：
  - 确立为阿瑞忒**「同伴羁绊复盘 & 战略切换据点」**：① 每日不同时段轮驻一位社团同伴（晨：杨子英 / 午：柳宇龙 / 暮夜：姜梓或主线特殊事件），提供专属**高额体力恢复 + 同伴好感 + 模拟复盘思路**（并可直接在此切换当前随行协战同伴，不必来回跑社团工坊）；② 作为序章/第一章重要情绪谈心与俯瞰海湾/红月的剧情舞台。
- **空间布局蓝图（先布局后出图）**：
  - **画风翻新**：彻底去除旧图的灰黑脏混凝土、锈斑与模糊大树叶；改为**洁净淡蓝白瓷砖天台 + 清透浅蓝铁艺护栏 + 远景碧海白云与白色灯塔**（参考 `01_天台_清透日光留白构图` + `02_护栏黄昏`）。
  - **左区（0–35%）**：天台铁门与楼梯间小屋（干净几何体块，留白给左上 HUD）+ 墙边校内饮料贩卖机（可点选触发小趣味/买水）。
  - **中区（35–65%，视野主焦点）**：通透护栏与蔚蓝海景 + 一张洁净原木遮阳桌椅（前景桌面可作 Layer 3）；**Slot A（常驻同伴位）** 自然倚在护栏旁或坐在木椅边，配柔和地影与风吹发丝/微呼吸动效。
  - **右区（65–100%）**：留出通透天空与空白地坪，专门承接**右侧统一功能停靠栏**（`午后复盘 · 1活动` / `切换随行同伴` / `和同伴聊聊` / `← 回社团教室`），绝不遮挡人物与海景。

### 2. 校园商店（`shop`）
- **功能定位**：实体战术刻印卡与补给购买 + 店务兼职赚零用钱 + 校内传闻情报源。
- **空间布局蓝图（彻底解决 NPC 嵌入突兀）**：
  - **视角重构**：放弃旧图斜角混乱走廊，改用 **《Angel 24》正面微仰平视构图**（参考 `01_场景画风与空间构图/03_商店_正面平视柜台分层_Angel24.webp`），配合暖木+奶油白+清透蓝绿校园小店配色（比照已有的 `shop_counter_plate.png` 温暖基调，但画面更简洁赛璐璐化）。
  - **Layer 1（后景）**：左侧整齐透明冷饮柜与文具架、中后方干净货架与黑板菜单（贴「今日新品刻印卡」小牌）、右侧采光窗与快递纸箱区（兼职热区）。
  - **Layer 2（NPC 槽位）**：**唐小满（Slot A）** 正面居右中偏后站在收银台后方，仅露腰部以上；若未来有主线同学来逛店，**Slot B** 预留在左中货架走道处。
  - **Layer 3（前景遮挡层，关键！）**：画面下方 `y=660..1080` 独立拆出**一整条干净温暖的原木前台柜台（含招财小摆件、收银牌、橘子汽水展示瓶）**，真实遮住唐小满下身，彻底融进画面！
  - **交互融合**：进入商店默认直接看到唐小满微笑迎客 + 一句轻气泡台词；点击柜台/「查看商品」时，**画面平滑左移/柔焦背景，左侧展开清爽货架窗口，右侧保留唐小满实时表情反馈**（参考 `03_交互窗口与商店选拔赛/01_商店左货架详情与右店员同屏融合`）。

### 3. 体育馆（`gym`）
- **功能定位**：① **主线核心入口 ——《阿瑞忒巡回代表选拔赛》正式赛场**；② 日常《模拟训练路线》刷材入口；③ 赛前卡匣整备与竞技同伴柳宇龙据点。
- **空间布局蓝图（新增主线选拔赛视觉中心）**：
  - **视角重构**：干净高挑的日光拱顶室内体育馆（参考 `04_体育馆_清透日光场馆` + `05_全息赛事场馆氛围`），去油腻地坪强反光，改为清爽温暖木地板 + 蓝白馆内钢架。
  - **中左视觉主焦点（主线选拔赛入口）**：馆内中央明确建起一座**「阿瑞忒学园护盾裁决擂台」**（蓝色发光地坪圈 + 上方悬挂清晰的赛程横幅与电子计分牌/全息投影屏，第一章通关后点亮发光效果！），一眼就知道这是主线选拔赛正门！
  - **右侧区域**：**模拟训练战术白板与器材架**（日常训练路线入口）+ **赛前整备长椅**（放着折叠战术卡匣箱，快捷进工坊）。
  - **NPC 融合**：**柳宇龙（Slot A）** 站在擂台右侧台阶前（全身立绘严格踩在木地板地坪线 + 脚底柔影 + 馆内高窗斜光色调统一）；选拔赛期间，**Slot B** 在擂台边缘可出现主线裁判/姜梓或当轮挑战对手。
  - **选拔赛弹窗升级**：点击擂台或右侧停靠栏「✦ 阿瑞忒代表选拔赛」，打开参照 `03_选拔赛窗口` 的双栏竞技面板——左栏展示叶舟当前卡组/共鸣状态与直达工坊按钮，右栏 3 张清晰递进赛程卡。

### 4. 图书馆（`library`）
- **功能定位**：① **第一章第一幕核心主线触发地**（窗边偶遇研读人类恋爱小说的黄秋枫 + 姜梓赶来通报限幅器异常）；② 牌理研习赚练习点；③ 收集与阅读《阿瑞忒风物纪要》。
- **空间布局蓝图（解决巨书遮屏与主线 NPC 无位置）**：
