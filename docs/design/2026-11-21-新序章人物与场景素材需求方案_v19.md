## 三、自检与合入流程

1. 使用压缩包内 `06_Tools/qa_check_v19_prologue.py`（纯 Python 零第三方依赖）按阶段校验产图尺寸、色深、透明比例与比例范围：
   ```bash
   python 06_Tools/qa_check_v19_prologue.py <生成输出目录> --group p0
   ```
2. 按 manifest 中 `godot_drop_in_path` 投放进仓库后，执行 Godot 资源导入与隔离回归验证：
   ```bash
   Godot_v4.7.2_console.exe --headless --import --quit
   python tools/run_godot_tests.py --godot "<Godot可执行文件>" --suite all --resolution 1600x900
   ```
