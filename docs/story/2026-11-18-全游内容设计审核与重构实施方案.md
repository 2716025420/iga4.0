# IGA 全游内容设计审核、整改重构与测试精简实施方案（v2 · 流程与胶片手帐中枢重构版）

> **文档日期**：2026-11-18（依据主创当日最新审阅决策修订）  
> **核心原则**：**不被早期有矛盾的设定（如“学生智能终端”）与早期草图坐标束缚**；确立**「标题页 → 独立序章 → 社团教室主场景引导 → 日常游玩循环 ⇄ 剧情交替推进」**的正常商业 RPG 结构，并将游戏最具辨识度的**《放映档案室》**升级为集记录、成就、委托奖励领取于一体的核心中枢。第 2–5 章未定剧本与持卡人严格留白，不擅自补全。

## 一、全游现状深度审核结论（五大根本症结）

### 1.1 游戏宏观结构倒置：把第一章做成了“脱离游戏场景的孤立序章”
- **现状问题**：点击「开始新游戏」后，[phase_two_content.gd](file:///d:/just-life-main/just-life-main/scripts/global/phase_two_content.gd) 直接将 `n0` 至 `n_find_yang` 共 9 幕一路播完，**把本该承担“10–15 分钟开篇引子＋首战教学”的序章拉成了一整章脱离游戏本体的线性电子小说**，全程几乎没有引导玩家真正使用社团教室、校园地图、商店与养成场景。
- **断崖后果**：当第 9 幕结束、台词刚喊出*“下一站，向诺莫斯出发吧！”*，[game_state.gd](file:///d:/just-life-main/just-life-main/scripts/global/game_state.gd) 把玩家切回社团教室，此时黑板瞬间变成空洞的`日常自由时间`，世界图上包括诺莫斯在内的五区全部锁死，`CalendarContent.STORY_DATES` 为空，导致玩家**刚以为游戏正式开始，却发现没有任何主线目标、地图和后续钩子**。

### 1.2 「学生智能终端」设定枯燥且与美术气质冲突，缺乏成就/目标回馈中枢
- **设定矛盾与体验平庸**：早期文档曾提出平板形态的「学生智能终端」并衍生出“学籍终端协议、终端防火墙覆写”等偏生硬的 IT 说辞；而游戏实机最打动人的基调是**温暖木质社团教室、拍立得照片、胶片放映机、实体战术刻印卡与手帐纸签**。
- **现行《放映档案》空洞**：目前点击桌面的「放映档案」进入 `PlayerWorkspace("records")`，映入眼帘的却是一张过曝空校园走廊图贴几个彩虹条，既没有真正的胶片放映质感，也没有成就任务板和奖励领奖仪式感（`PlayerJourney.MILESTONES` 仅 5 条零散文字藏在角落）。

### 1.3 场景游玩循环断链、NPC 消失 Bug 与死房间
1. **行动点规则倒挂**：[home_screen.gd](file:///d:/just-life-main/just-life-main/scripts/home/home_screen.gd) 聊天扣 1 点活动点、[player_journey.gd](file:///d:/just-life-main/just-life-main/scripts/global/player_journey.gd) 卡牌升级也扣 1 点活动点，把本该自由交流和整备的社团操作变成惩罚。
2. **驻场人物消失 Bug**：[campus_screen.gd](file:///d:/just-life-main/just-life-main/scripts/campus/campus_screen.gd) `_build_place()` 命中 `SceneDesignCatalog` 后调用 `_build_scene_objects()` 直接 `return`，跳过 `_build_actor(npc_id)`，导致图书馆（林知夏）、商店（唐小满）、天台（柳宇龙）**全部变成无人的空房间**，且左下角常驻 `"TEST · 场景与交互提案"`。
3. **死房间与剧情地点缺失**：概念化 `library` 遗漏了前往 `study`（自习室）的入口使其成死房间；商店后仓 `stockroom` 功能空壳；**序章与第一章最关键约会与高潮舞台《旧公园》在校园地图里根本不存在**。
4. **经济闭环断裂**：全游缺乏可再生的「零用钱」获取玩法（商店首日倾泻全 16 张卡，但玩家买完两张即永久缺钱），且通关后缺乏明确的中期验证 Boss 擂台。

### 1.4 早期临时美术与占位坐标束缚视觉表达
- **校园地图**（`campus_vermilion_first_pass.png`）与**世界总图**（`world.png` 中世纪浮空岛帆船）画风严重跑题；
- **卡匣整理工坊**（`prep_scene_room_wide` / `prep_scene_structure_wide`）被早期粗平涂蓝塑料盒坐标死死限制，质感远低于社团教室；
- **7 处校园日常场景**虽已有洁净的 `2340×1080` 底图，但全部缺失 `1920×1080` RGBA 透明前景道具拆层（`*_objects.png`），交互停留在纯背景上套多边形；
- **第 2–5 章 20 余个 `#20262D` 灰黑底 `"TEST 工程占位"` 页**及底栏旧版 `反抗联盟 / 教会圣地` 按钮直接暴露给正式玩家。

### 1.5 自动化检查测试过度膨胀，反向绑架开发
- `tools/tests/` 下 4 个脚本累计 **1,510 行**，三环境累计跑 **5,636 项检查**与近 80 张截图，其中 **65%+** 在空壳 `*_shop_test` / `*_arrival_test` 中反复空转，还把 `"TEST · "` 与旧坐标写死进断言。

## 二、可实践的全面整改方案（全新结构 + 胶片手帐中枢 + 场景闭环）

> **设计总纲**：彻底甩掉“终端”包袱与早期临时画面束缚，确立 **「序章引导入部 → 社团主场景学会整备与领奖 → 日常场景探索与剧情事件交替推进 → 旧公园高潮与代表选拔决胜」** 完整体验。

### 2.1 重构后的游戏宏观流程顺序

```text

  ↓ 点击「开始新游戏」
【Stage 0 · 独立序章（约 10 分钟，精炼高钩子）】
  ① 早晨上学路：目睹高年级生强抢初始刻印卡，叶舟以基础护盾模式替转校生黄秋枫解围
  ② 次日运动会伏笔（新增）：体育生冲线力竭视角下，第 4 名的黄秋枫呼吸平稳得异样；随后在操场/校门与柳宇龙完成 3 卡教学热身切磋（结识杨子英）

    1) 点击【卡匣工坊】：把第 4 张行动卡装进卡垫（学会配队与升级）
    2) 点击【放映档案室】：为“正式入部”成就盖章，当场领取【社团启动零用钱 + 材料】新手包，看到下一阶段委托目标
```

### 2.2 社团《放映档案与成就领奖室》四合一中枢设计（正式替代学生终端）
废除平板终端概念，保留并重制游戏最有记忆点的**「胶片放映室 + 盖章手帐」**界面，所有记录、任务与奖励回馈集中于此：
1. **【任务委托与成就盖章台】**：取代孤零零的 5 条 Milestone。划分为**「主线阶段筹备目标」**与**「校园探索/对战成就」**，每达成一项即可**盖下红/金社团印章并直接弹出领奖特效**，持续投放**零用钱、练习点、强化材料与限定战术卡**，成为玩家推动游玩循环的直接驱动力。
2. **【故事胶片与当前指引】**：投影银幕回放已解锁的剧情片段、记录遇见的人物与当前主线/选拔目标。
3. **【同学拍立得羁绊墙】**：以拍立得相片展示杨子英、柳宇龙、姜梓及校园人物，直观显示好感等级与对应**协战技 `Lv.1 → Lv.2 → Lv.3` 实战强化预览**。
4. **【社团收纳箱】**：清晰分类管理橘子汽水补给、练习素材与剧情关键纪念信物。

*(注：《十二星座图鉴》继续保留在社团黑板快捷入口，作为永久剧情收藏册与战场共鸣核心切换页。)*

### 2.3 阿瑞忒八大场景「一景一核心职能」与经济闭环
- **行动点总规则**：每日 3 时段（早晨/下午/夜晚）× 每时段 **3 点活动点**；**聊天寒暄、工坊编组与升级强化、进店交易、查看放映室/图鉴全部 0 消耗**，活动点仅用于高产出行动。
- **八大场景精准分工**：
  1. **社团教室（Home）**：大本营中枢——黑板主目标、**卡匣工坊**（全新自由布局精绘）、**放映档案与成就领奖室**、**十二星座图鉴**、姜梓免费交流。
  2. **图书馆（合并原 `study`）**：林知夏常驻；**「牌理研习」**（1 活动点 = `+35 练习点` + 逐篇解锁《学园风物纪要》）+ 免费阅读。
  3. **校园商店（合并原 `stockroom`）**：唐小满常驻；**16 张卡随阶段/印章分 3 阶解锁上架**；新增**「店务盘点兼职」**（1 活动点 = **`+100 零用钱`** + 概率得橘子汽水），彻底打通零用钱再生来源。
  4. **体育馆 & 校内代表选拔赛主擂台（`gym` + `arete_arena`）**：柳宇龙常驻；《模拟训练路线》稳定产出强化材料；《代表选拔赛主擂台》提供 3 场阶梯守门 BOSS 战与最终首席代表对决。
  5. **教学楼天台（`rooftop`）**：柳宇龙/杨子英轮换常驻；「午后战术复盘」（1 活动点 = 回 `40 HP` + `+15 练习点` + `+10 熟悉度`）。
  6. **旧公园（`old_park` · 新增实景地图地点）**：序章/第一章关键约会与红月变故实地舞台；事件后可到此长椅与贩卖机小径重温互动。
  7. **沿海步道与阿瑞忒海滩（`coast` / `beach`）**：彻底移除 `TEST`；支持「邀约同伴海风漫步」（1 活动点 = `+15 熟悉度` + 专属海岸短对话）。
  8. **学生宿舍（`dorm`）**：简洁床铺（休息推进时段/过夜回满体力）与书桌（今日小结与手动存档）。

### 2.4 第 2–5 章干净隔离与 `TEST` 清零
- 移除所有界面的 `"TEST"` 字样、灰黑 `#20262D` 调试页与旧版 `LEGACY_REGIONS` 底栏兼容按钮；
- 在全新的近未来《六地区巡回导览总图》中展示六区风貌，击败阿瑞忒首席代表后正式点亮诺莫斯卡片为「已取得阿瑞忒代表通行章 · 第二章敬请期待」。
