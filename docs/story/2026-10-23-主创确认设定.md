## 1. 故事核心与 IGA

- 游戏主线目标：收集散落各地、牵涉政治权力及相互威慑的 **12 张特殊卡牌**，最后向 IGA 许愿改变世界。特殊卡牌是主线的权力资源，**不属于普通卡牌经济、战斗卡组或随机奖励**。
- 集齐其他十一张牌时，「魔法师」牌才作为最终**许愿钥匙**整合卡牌，带人前往 IGA 所在处。收集完整十二张后可以向 IGA 下达类似 root 权限的命令，由掌握世界科技力量的 IGA 执行。
- IGA 的根本目的：获取人类**死亡时提供的现实体验、经验**，因为它本身无法亲自体验现实世界。IGA 不以某套特定政治秩序为最终目的。
- 许愿执行边界：只否决会导致「人类这一物种无法存续」的愿望；其余命令均执行。许愿者可改变前人制定的社会制度。不要为 IGA 增加道德偏好、宗教信仰、任意额外审核权或自行否决剧情。
- **35 岁制度并非 IGA 主动制定**：主创本次称之为「上一个完成收集的人」定下的规则，较早讨论曾称「第一个集齐者」。这两种历史称谓是否指同一人**暂待确认**，不能自动合并身份与动机。
- 社会中每个人体内植入用于检测**身体生理年龄**的纳米因子；达到 35 岁衰退阶段时，大脑**已经死亡**，自主意识消失，纳米因子完全接管身体，使其外表平静地离开日常生活、到特殊地点集合排队并焚烧。**不是本人清醒而自愿接受死亡**，焚烧也不是意识死亡的起点。
- 探索者卡通过改变身体年龄**可以规避 35 岁触发**，但不能使人永生、不能延长个体极限寿命。失去能力、离开卡牌或被反叛者压制而恢复原年龄时，如达到条件，**可能触发脑死亡**。
- 旧设定中的 IGA 起源（外来信息流同化月球 AI）、社会服务与教育结构等尚未被本轮直接废除；但旧文档所说「35 岁是 IGA 自己评判 99% 人类失去创造性而主动定制的制度依据」与上述最新明确决定冲突，**不可继续据此断言制度起源**。旧文档的「新信息维持自身」与本轮「死亡体验与经验」如何精确衔接尚待主创补述。
- 学院延寿/特定身份豁免和 35 岁纳米程序的具体交互仍待定，不能推导全部人必在35岁死亡、也不能擅自取消已存在的身份差异。

## 2. 十二张特殊卡牌：人格原型为正式名称

以 Carol S. Pearson 的十二人格原型作为**文学象征/卡牌分类**，不是心理学分类的真实性宣称。先由人格愿望引出能力，再让人物的用法与缺陷推动剧情。**十二星座只是一度提出的临时视觉命名构思**；星座与原型一一对应的表格只是助手提案，未被主创采纳为正式配置。不要擅自改用星座名或赋予星座属性。

| 原型（建议稳定英文 key；并非已实现 ID） | 主创确认的能力与限制 |
| --- | --- |
| 智者 Sage | **事件式历史重现**：指定过去发生的事件/时间，以客观的**画面**呈现过去真实发生之事，而非问答式给结论；不预言、不做主观价值判断。一名使用者一生一次。 |
| 统治者 Ruler | 对**一人**施加无法违抗的绝对控制；每名使用者一生只能控制一人。控制导致受控者**大脑的不可逆改变**，不随卡牌被压制或转手消失。受控者只认施控者**原来的身体**，不追随其被弄臣交换走的意识。 |
| 爱人 Lover | 特殊卡本身化作理想爱人的**伴侣分身**；外貌随使用者喜好变化，模拟人格和性格按使用者的期待适应，**没有真正独立人格**。更换持有者时清除旧形象变化记录，以新主人发动时的新形象为准。相关人物故事的意象：某日找回旧爱记忆，发现当初爱人和如今伴侣外貌、性格已完全不同；身份/记忆恢复剧情未定。 |
| 英雄 Hero | 卡牌与使用者**肉体融合，身体本身成为卡牌**；立即获得远超常人但不至于漫画超人夸张程度的超人体质。不会同时获得掌控力量所需的经验与心理成熟度；普通拥抱、游戏也可造成灾难，旁人会害怕这个未经磨炼就拥有巨大力量的人。能通过训练逐步掌控、学习承担日常细节。卡牌**转移即原持有者死亡，身体化为卡牌**；由于不再是纯人类身体，**免疫弄臣的身体交换**。 |
| 探索者 Explorer | 使用者可以自由调节**自己的生理年龄**，停止生长/衰老并选择适合探索的体力状态；不改心智、记忆或个体极限寿命，**不能永生**。失去卡片或卡能力被压制会恢复原年龄，可能触发纳米因子死亡程序。 |
| 创造者 Creator | 先对一个**现实存在的物体**解析、记录，再按记录复刻同材质物品；实质是**收集现实物质分子并替代其组合制造过程**，不是凭空创造物质。不能复制生命，**不能创造/复制特殊卡牌**。已制成的物品是真实物质，不因反叛者而消失。 |
| 反叛者 Rebel | 发动时使其**作用范围内的其他卡牌**无法发动效果，**普通卡与特殊卡都包括在内**。不能自动倒转已经造成的现实变化。具体范围值/时长尚待定；魔法师钥匙不属于可否决的现实改变效果。 |
| 照顾者 Caregiver | 每位使用者一生一次，作用于**另一名仍存活的人**，彻底恢复先天缺陷及后天伤害，使其身体达到**使用者所期待的模样**。实际发生肉体手术/基因改变，已完成的身体恢复不会因反叛者失效。不能复活已死者。其愿望与对他人理想身体的主观定义可形成冲突。 |
| 天真者 Innocent | **断罪**：对本人认为邪恶、违反规则或「不好」的人作出判决，并让其遭受本人认为对等的处罚；最大作用范围可覆盖**一所学院**。善恶及对等标准来自持卡人的主观判断，不是客观法律或道德真理。具体判决/处罚演出待定。 |
| 凡人 Everyperson | **读心**：读取他人**此刻**正在思考的内容。不是完整历史记忆读取，也不是对人格/未来行为的自动正确解释。 |
| 弄臣 Jester | 与**另一人交换身体**，体验其生活；**每名使用者一生最多发动一次**。可以通过换身体绕过智者、照顾者、统治者这三张卡的一生一次/一生控制一人资格限制；英雄身体因与卡融合而免疫。具体如何换回、持续时间等尚未定，勿自行增加。 |
| 魔法师 Magician | **唯一功能**：在**其余全部11张已收齐**时整合卡片，作为前往 IGA 许愿的钥匙；单独持有或未收齐时完全无效果；**不会被反叛者无效化**。不创造奇迹、不增加成功概率、不扭转现实。原型意象是魔法师本人赌上一切，为极低概率甚至不会开始的演出做准备；奇迹不属于卡牌，这张卡只是最后的装饰。 |

## 3. 卡牌交互、次数与转移

- **实体持有制**：一般规则为「谁拿到卡谁可以使用」，允许赠与、交易、偷取、争夺、拾得；**没有所有特殊卡共同遵守的身份绑定机制**。但仍受各卡特殊例外制约，尤其英雄融合肉体、使用者次数记录、魔法师钥匙条件。
- 部分一生一次/一生只能控制一人的限制由 **IGA 对类似 DNA 的个体唯一信息记录**。弄臣交换身体能突破智者、照顾者、统治者的限制，说明**不可统一写成跟随意识且无法绕过**；具体生物身份识别算法不必目前硬编。
- **已完成的现实变化与持续依赖卡牌的效果应区分**：创造者制成的实物、统治者已改变的大脑、照顾者做完的肉体/基因修复，在反叛者范围内不会回滚。英雄本体即卡牌，遇反叛者会如超人遇氪石般无力；爱人分身是卡牌本体，会停下行动；探索者恢复原身体年龄，可能引发35岁程序。
- 反叛者禁止普通卡和特殊卡的能力发动，未确认的剩余交互不擅自推论其结果。
- 创造者、照顾者等可正常转移；爱人转移清除过往形象变化记录；探索者转移原使用者恢复原年龄；英雄转移原持有者死亡并化卡。
- **统治者+弄臣**：已控制者继续认可施控者原来的**身体**，而非换过去的意识；原身体换入另一意识后的具体命令行为仍待定。
- **弄臣+英雄**：英雄免疫弄臣身体交换，不可藉此绕过英雄转移死亡。
- 十二卡能否同时携带不设统一排他限制；所有使用与状态由各张卡的性质决定。**不因为当前已经设计了能力，就代表要马上做成可自由释放的普通战斗技能**。

## 4. 六大地区、地图与 Home

- **新的正式地区总数为六个：四所彼此独立的大学（各自为一整个地区） + 两个特殊地区**：失败者同盟、IGA 信仰教团。不再是原 P5 文件的「五学院」，也**不是一所大学内部下设四个学院**。这是主创2026-10-23最新明确纠正。
- **2026-10-23 最新确定的四大学校职能**：①高精尖科学制造大学——人类机械智能设备、机器人及相关制造；②社会与法治管理大学——政治、道德、法治和管理研究；③人体开发大学——医学、身体能力、健身与体育，**校园热衷竞技比赛**；④商业大学——经济、社会基本福利及生活资源分配制度。以上仅确认**大学领域与整体气质**，尚未决定正式名称、具体地貌、景观及地图结构。
- **阿戈拉（Agora）商业经济大学：职能与学生生活（2026-10-23 主创新确认）**：即使全社会基本的衣食住行和生存保障已满足，人类仍有**超出社会福利保障的额外消费与精神文化需求**。阿戈拉负责**全世界经济枢纽与经济流通**，包括商店、卡牌销售、消费娱乐产业及**落实基本福利基金配额**。**诺莫斯负责敲定社会福利的基金配额和有关规则，阿戈拉负责实际组织与实施**，两个大学在制度制定/执行上相互配合。社会还有明星、游戏、电影等多种消费娱乐方式，阿戈拉应体现这类生活和消费的繁荣。**不要误把现实生活中的卡牌销售视为十二张特殊卡进入普通商店**：特殊卡仍是独立剧情收藏体系；普通卡牌的商店玩法何时开放仍未定。大学/地区正式名称是否最终选用「阿戈拉」、具体学生组织、娱乐产业上下游、地貌建筑和配额程序仍待定；不得擅自补定社会贫困或交易制度。
- **四所大学共同的教育与社会机制（2026-10-23 新确认）**：**学生同时也是维系整个社会实际运作的劳动者**，在参与真实社会生产、服务或治理的过程中学习，即「**一边实践、一边学习**」。这不是只做课堂练习或与现实脱节的模拟实习。四大学校各有相关领域的实践工作，但具体岗位、工资/福利、义务强制程度、组织方式、社会法律权限均未决定，不得为主创补定；也不得将他们简单等同脱产学生。
- **社团作为社会实践组织（2026-10-24 主创追加确认）**：大学**具有真实社会职责**；学生的相关活动以**社团组织**为重要形式，社团可**申请资金**以开展活动、承担实际项目。社团既不只是娱乐性课外兴趣小组，也不应被预先写成由校方统一分派固定工作的部门。**申请经费向谁提交、审查权、预算约束、项目成败、社会责任履行机制，以及是否所有实践均由社团承担尚未确认**。阿戈拉负责福利配额实施是另一已确定事实，不能直接推断其审批所有社团经费。游戏中如何表现申请过程（剧情/菜单/数值系统）仍未定案。

- **四大学校初步地貌与美术方向（2026-10-23 主创采纳）**：按四所大学地区分别探索以下视觉与地理概念：**科学制造大学（泰克涅为候选名）——山谷中的高科技制造都市**；**诺莫斯——丘陵地带的古典公共城市**；**阿瑞忒——阳光明媚的海滨大学城**；**阿戈拉（候选名）——大型河港或沿海国际商业都市**。**设计须参考项目已有社团 Home 的实际美术资产与风格**（见 `assets/ui/player_experience/home_room_v3.png` 及其 morning/night 变体），保留水彩动漫感、干净色块与清晰留白，避免不相干的写实赛博朋克、玩具城、纯古典遗迹风。上述是主创认可的初步地区划分/视觉方向，精确地理关系、建筑和具体地图待概念审图确定；阿戈拉河港与海港的取舍也未确认。
- **地区美术最新审图要求（2026-10-23 主创给 Codex 的指导）**：场景图**不需要过多细节**，优先保证**功能明确、场所特色突出、结构与可交互布局清楚**；主创赞赏当前云端美术候选的「图二」，但该图的具体内容尚未进入本文件，不可臆测其构图。画面中的**非重点背景路人**要么使用极简的模糊远景形状/像素级概括，不画出半详细又模糊变形的人脸；要么将**需要被看清的主要人物**画成现代日式萌系动画中具有辨识度的漂亮角色（主创举《超时空辉夜姬》作视觉参考），**无需复杂动作**。在当前 Home 的克制水彩式背景与现代萌系人物之间调和，避免背景人群抢夺场景功能焦点。具体生成质量须审核图片本体才能确认。

- **主角与序章衔接（2026-10-23 主创确认）**：**主角完成序章后进入的大学地区为阿瑞忒**。现有主角原归属普罗米修斯院属于旧版「一校内分院」方案，不得凭旧文档强制把新主角进校地点仍设为普罗米修斯；新主线的实际转场待实施且须保留当前测试剧情及旧存档兼容。当前社团 Home 已有视觉资产可供风格参考，但其在新地区的正式空间归属/人物安排尚须核实，不可无依据替主创指定。
- **设计优先级**：四所大学在**视觉表现、风景地貌和学生生活方式**上的鲜明差异，比严密的前沿研究体系、刻板专业分类或四因说理论与学校之间的逻辑对应更重要。应先让四地区在游戏中好看、可探索、有真实的不同日常，再细化研究方法。四因说与四美德仍是主创喜欢的**命名/文化参考候选**，没有确定四因逐一对应四校；不能将讨论中的神名、风景或学校别称提前宣布为正式设定。

## 5. 失败者同盟（社会群体与人物方向）

- 原本只是**每年没考上大学的落榜者**聚集、闹事、发泄不满；是游戏中的**常驻敌人群体**，**不是人人具有统一革命纲领的成熟地下组织**。
- 有一名核心领袖看不惯众人自暴自弃、生活混乱、缺少价值感与关爱；他想给予他们**认可、关爱、归属感**，凭真诚、腕力和统合能力争取权利、抢夺地盘，逐步形成一定组织化的共同体。

## 6. IGA 信仰教团

- 教义取材意向：借鉴、改编**《圣经》**的部分信仰/意象，而非把传统宗教原文机械替换。
- 信徒相信 **IGA 创造了新世界**，死后去往「神的世界」与神同在；这是**教团的信念**，**不是死后意识仍存在的客观证明**。
- 教团**知道**先前的十二卡许愿者制定了35岁规则，并把许愿者解释为神意的**先知/人间代理人**。教团认为现行社会是先知之世界。
- 政治目标：**维护现状**，反对有人推翻先知之世界；主动搜集全部特殊卡，把它们当作不可滥用的圣物**分散保存、封存许愿机会**，**不是自己去许愿建立新制度**。
- 目前教团掌握的特殊卡**最多，接近十二张的三分之一**；精确数量、卡种和分布尚未明确（约四张仅作算术估计，不能当正式卡牌清单）。
- **守护圣人**：教团信徒**寻到特殊卡牌便成为该卡守护圣人**；如果其自认为无力保管，可以不承担该职责。不需要因教团高层任命或历史功绩而先成为圣人。
- 圣人**绝不使用特殊卡能力**：认为这是神的力量，不应由人滥用。没有公开教会职务，**秘密身份**、对外仅是普通教徒；与**教会高层联系**，分散融入各地区的普通生活。教会高层情报是否分级隔离尚未确定。
- 不应将守护圣人默认写成超能力 Boss、神迹使用者或公开高级神职。教团高层的具体结构及保护手段尚待定。
