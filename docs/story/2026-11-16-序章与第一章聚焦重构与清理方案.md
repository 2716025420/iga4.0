## 一、核心审核结论与设计定型（方案 B）

### 1.1 打通的新游戏 → 第一章完整游玩闭环
1. **标题页开局直达体验**：点击 `开始新游戏` 后，不再静默空落入空桌面，而是直接切入序章／第一章开篇（`campus_morning`「樱林解围」→ 认识黄秋枫与杨子英）；随时可通过「暂离」回到社团教室整备，未完结期间黑板主按钮（`PrimaryActivity`）动态显示当前行程目标与 `继续行程`（`PlayerJourney.home_snapshot()` 返回 `action = "story"`），彻底修复此前 `home_snapshot` 与 `_start_chapter` 断链导致的新档无法开启主线的问题。
2. **精炼波浪式序章＋第一章九幕结构**：
   - `n0 · 樱林解围`（开篇序章/校园清晨）：解围转校生黄秋枫，初见杨子英与终端护盾规约。
   - `n_gate · 校门切磋`（**新增第一场低门槛实战教学**）：对话后直接进入对 `柳宇龙` 的「非致命终端护盾切磋」教学战（开局预置 **3 张初始卡组**：`破隙突刺`＋`便携偏转盾`＋`冰镇补给印`，保留 `连携压制弧` 于卡库等待玩家首次体验工坊编组），配双步纸签提示「出牌看冷却」「先看意图与护盾」。
   - `n_affairs · 旧园名录`：午间遇姜梓核对巡回赛名录与终端覆写日志，正式解锁姜梓随行。
   - `n_dusk · 黄昏轻吻`：放学旧公园走廊双层视差（`dusk_corridor`），表白倾向／笨拙轻吻与「去自动贩卖机买橘子汽水」支开转折，红月警报骤响。
   - `n_guard · 门岗封锁`：首场 **红月超限战（Overclock）**，突破被外部指令劫持的门禁卫兵。
   - `n_rescue · 灰区奇袭`：街角目睹灰区女特工重创秋枫（`damaged_fiber` 光纤露芯揭示伪人本质），杨子英赶到并肩作战。
   - `n_robot · 拦截机械`：与同伴协战击停灰区重装拦截机。
   - `n5_boss · 红月超限`：**移除过时「校长 (`principal`)」设定**，替换为灰区女特工驱动的**「灰区超限猎杀终端 (`ch1_hunter_mech`)」**（全员协同，触发 3 卡高燃 Cut-in 协战演出）。
   - `n_find_yang · 白羊觉醒`：转场双层视差 `qiufeng_crystal`（黄秋枫结晶封印＋循环闪烁 `crystal_shimmer`）→ `red_moon_finale`（四人夜色誓言），觉醒 `#01 白羊座·英雄` 母卡并解锁「扰频假票令」与自由巡回探索。
3. **通关后与日常校内循环**：
   - 完结第一章后，社团教室黑板主引导切换至自由时段日程、`DayCycle` 三时段休息、体育馆「模拟训练路线」（扩展至多组校园分支遭遇事件池）及阿瑞忒实体商店/工坊强化流转。

## 二、UI/UX 与操作体系升级

1. **对话演出与操作 ([dialogue_screen.gd](../../scripts/story/dialogue_screen.gd) / [school_dialogue_presentation.gd](../../scripts/story/school_dialogue_presentation.gd))**：
   - 修复曾因 GDScript 类型推断导致的训练节点「拾到的留言」卡死问题，增补全项目脚本/场景编译与实机入场回归检查；
   - 铭牌左下角小头像支持全员角色（含 **黄秋枫** 各神态与 **灰区女特工**），不因旧白名单而空白隐藏；
   - 句末文本打字完成后显示温和呼吸翻页提示标，Auto 模式停留时间按文本长度动态微调；
   - 修复窗口重排 / 进入时的 `_current_cutscene_id` 持久化，确保逐行触发过场（`qiufeng_crystal` / `red_moon_finale`）不被重置。
2. **战斗交互与可读性 ([combat_screen.gd](../../scripts/combat/combat_screen.gd) / [combat_presentation.gd](../../scripts/combat/combat_presentation.gd))**：
   - 新增桌面端战斗快捷键：**数字键 `1`～`5` 快速选择/打出对应槽位卡牌、`Tab` 切换目标敌人、`Space` / `Enter` 结束回合、`H` 打开/关闭回合记录**；
   - 将首战教学便签优化为带暖纸底框、可随操作推进的轻指引；
   - 战败结算界面保留「返回社团教室」之外清晰提示推荐整备行动卡，Boss/节点首次获取卡牌或首章觉醒可配合 `RewardCardPopup` 呈现爆星庆贺。
3. **社团 Home、商店与训练路线微体验**：
   - 黑板主按钮与桌面 `TalkJiangZi` / 工坊入口增加更清晰的轻反馈提示；
   - [campus_shop_panel.gd](../../scripts/campus/campus_shop_panel.gd) 在保持全 16 张战术卡售卖的同时增加「全部 / 未拥有」便捷过滤与更明确的货架滚动计数；
   - [school_exploration_routes.gd](../../scripts/global/school_exploration_routes.gd) 把单一的「拾到的留言」模板扩充为 **8 组** 轮换校园微故事（含叶舟、杨子英、柳宇龙、姜梓及匿名旧公园纸条）。

   - UI：`sfx_ui_click.wav`、`sfx_ui_hover.wav`、`sfx_page_flip.wav`、`sfx_modal_open.wav`、`sfx_save_chime.wav`
   - 战斗/系统：`sfx_card_play.wav`、`sfx_shield_up.wav`、`sfx_heal.wav`、`sfx_debuff_glitch.wav`、`sfx_counter_reflect.wav`、`sfx_hit_normal.wav`、`sfx_hit_overclock.wav`、`sfx_cutin_slash.wav`、`sfx_pack_tear.wav`、`sfx_zodiac_resonate.wav`、`sfx_victory.wav`
2. **外部制备 BGM 槽位（`assets/audio/bgm/*.ogg`，[audio_manager.gd](../../scripts/global/audio_manager.gd) 内建交叉淡入淡出与场景自动路由，放入文件即自动播放）**：
   - `bgm_title_serene.ogg`（72–82 BPM，清晨海风微光＋钢琴＋轻弦乐＋原声吉他，无缝循环）
   - `bgm_campus_daily.ogg`（96–108 BPM，盛夏青春轻松日常：木吉他/钢片琴/贝斯/轻鼓刷，无缝循环）
   - `bgm_dusk_memory.ogg`（66–75 BPM，黄昏温暖却带淡淡苍凉感：钢琴＋独奏大提琴，用于旧公园约会／结晶／回顾）
