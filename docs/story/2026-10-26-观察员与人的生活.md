# IGA · 2026-10-26 主创修订：观察员与人的生活

> **状态：主创已确认的世界观修订。** 本文优先于10月20日世界观、10月23日主创记录、10月24日六地区与10月25日星座卡记录中与本轮冲突的内容；未冲突的既有决定不自动撤销。本文只同步创作设定，不表示新主角、新剧情、死亡机制或日程玩法已经写入游戏。
>
> 本轮为创作上的改设定，不把废止的旧规则自动写成世界中曾经真实实施过的历史事件。

## 一、本轮已确认

### 1. IGA 与人类生活

- IGA 的出现改造了人类生活。
- IGA 已解决人类当今的重大矛盾：**战争、饥饿、疾病、死亡**。
- IGA 的设定改为**服务于人，持续记录人的生活信息**。
- **IGA 派遣观察员的目的，是获取并带回人类生活的信息，以进一步了解人类。** 这延续了旧设定中IGA希望了解人类的动机，主创提及“章鱼辟”作为这一观察构想的灵感参考；它不恢复旧设定中“只能在死亡时取得体验”的采集条件。
- 上述改善是新世界的成立前提。不能未经主创决定，擅自改成宣传假象、隐蔽屠杀、制造痛苦来采集信息或“幸福其实全是骗局”。
- 解决这些重大问题，不等于主创已经规定所有人都具有同一愿望、感受和关系；各地区仍以人的生活为故事对象。

### 2. 观察事项与主角身份

- 主角是 **IGA 派来观察人类的观察者／观察员**。
- 观察事项：**随机抽取一个人，跟随一年，记录他的生活**。
- 随机抽取的是被跟随的人，不擅自改成抽签选择观察员、选择最痛苦者或选择隐藏的特殊命运人物。
- 观察员会以一个**适合融入当地社区的身体身份**参与大家的生活。
- 观察员不仅在远处读取报告，也以身体与身份进入社区，与人共同生活；具体介入权限和技术能力尚未确定。
- 观察员的初始设定均为：**天真、善良、热情、不懂人心**。
- 这些初始特点属于主创确认；其成长过程、最终理解与结局未定。不能自行将观察员写成开场即冷酷、全知或熟练操控人类的人。
- **观察员通过模仿人类来生活与交往。** 其言行能够表现出天真、善良和热情，但“表现出情感”与“内在确有情感”不可直接画等号。
- **观察员知道自己正在模仿人类，也知道自己的真实身份；玩家在故事开始时不知道观察员的真实身份与这一模仿事实。** 这是已确认的角色认知与玩家认知差异。不能把观察员写成误以为自己是人的角色，也不能在开场用旁白、界面或角色内心独白直接向玩家揭示真相。
- **观察员是否由模仿而诞生真实情感，主创目前明确表示不知道。** 这是保留的创作悬问，不能擅自确定其只有程序化反应、已经觉醒、最终必将拥有真情或被证伪为虚假。
- **观察员原则上不能暴露自己的真实身份；如果身份暴露，会被回收。** 这条约束针对观察员，不能误写成人类居民被回收，或擅自等同于死亡、记忆清除等未确认后果。
- **观察期满一年，观察员必须携带观察数据返回月球，供IGA了解人类。** 月球是本轮已确认的返程目的地；观察员返回后的职责、关系与处境尚未确定。
- 身份暴露怎样被判定、由谁执行回收、是否存在例外，以及回收后发生什么，均待主创设计；不能把建议当成已确认的处置程序。

### 3. 地区的故事结构

- **每个地区讲一个故事，表达一种情绪。**
- 本轮确定的是地区叙事的组织原则；尚未给各地区分配正式故事、核心情绪、人物和结局。
- 已有四大学及两个剧情地区的名称、视觉主题、地图与Home结构没有因这句话自动撤销。
- 各地区故事如何与一次“一人、一年”的观察事项串联，尚待设计。不能自行把每进入一个地区就重新抽人、重新开始一年，写成正式流程。
- 观察员融入社区时需要守住身份秘密，并面对一年后必须返回月球的期限。这是贯穿各地区故事的已确认外部约束；是否成为某一地区的主要矛盾，由主创创作决定。
- **玩家初始不知情**是一条叙事信息呈现要求，不等于观察员自己缺乏身份自觉。揭示的时机、方式、是否有铺垫及揭示后玩家视角如何变化，尚待主创决定。

## 二、明确取消及失效的旧依赖

| 旧内容 | 新状态与处理 |
| --- | --- |
| 普通人35岁死亡、达到某生理年龄触发死亡 | **取消**。不继续作为世界运行规则或主线倒计时 |
| 35岁脑死亡、纳米因子接管身体、离开日常生活后集合焚烧 | 随旧死亡制度**失效**；不得仅更换名称继续使用 |
| 开始衰退就被清除、死后上传作为制度常态 | 不再沿用为本轮新设定；与服务、记录生活及解决死亡的前提冲突 |
| 99%的人35岁后没有创造性、“垃圾时间”作为现行制度依据 | 不再作为当前IGA政策或人物命运的默认解释 |
| IGA只能在人的死亡时取得现实体验 | 由**持续记录人的生活信息、派观察员共同生活**的新方向取代，不再把死亡当作默认采集入口 |
| 大学生依资格获得更多生命、未升学者35岁终结、孩子九岁后失去父母的固定处境 | 其中依赖强制死亡与延寿资格的部分**失效**；教育、工作、伴侣等其余制度是否保留另行确认 |
| 探索者／射手座失去能力、年龄恢复后触发35岁脑死亡 | **删除此触发后果**。年龄能力其余规则与新世界的关系待重审 |
| 旧教团维护先知制定的35岁死亡制度 | 该制度及其派生动机**失效**；教团在新世界中的信仰与冲突待重审 |
| 阿戈拉赌上生命后被管理、强制劳动直至死亡 | “劳动至死／失去生命”不能继续当作已成立剧情前提；整段人身支配安排与新IGA服务边界一起重审 |
| 主角必须因35岁终点收齐十二张卡改变世界 | 不能继续以旧死亡制度强制推出这一目标。特殊卡收藏与观察事项的关系待定 |

**取消年龄死亡，不自动取消所有含数字35的历史表述。** 旧起源纪年与故事年代尚未重新确定，本轮不凭“35岁死亡取消”擅自改写彗星、月球AI或公历起源年份。

### 主角与既有人物

- 叶舟、杨子英、柳宇龙、姜梓这些既有姓名及美术工作，不因本轮直接删除。
- “主角是观察员”现在优先于旧人类大学新生定位。
- **观察员是否继续使用“叶舟”之名、被观察者是谁、其与四位旧角色的对应，尚未确认。** 不把某人自动绑定为观察目标、观察员或女主。
- 融入社区的身体身份，不自动意味着占用已有人的身体、伪造已存在公民、获得他人全部记忆或能够无限更换身体。
- 与观察员建立关系的居民原则上不能得知其真实身份；居民对IGA公开服务的了解程度、被观察对象对观察事项是否知情，属于不同问题，尚未定案。

### 星座卡、终端与玩法

- 10月25日的不可交换剧情收藏、终端共用设备外形、实体地区商店等无冲突的制作约定仍保留。
- 十二卡是否仍承担最终主线、愿望权限如何与“IGA服务于人”衔接，尚未确定；不自动删掉收藏系统，也不擅自把一年任务改造成集卡考核。
- 涉及不可逆死亡、年龄极限、复活边界的卡牌描述需结合“死亡已解决”重审。不得擅自发明新能力或用旧死亡条件限制新世界。
- “一年”是叙事任务期限，期满须携带数据返回月球；本轮不把它未经设计就等同于365次休息、限时失败或新存档字段。身份暴露导致回收的剧情与游戏判定方式也尚未设计。
- 文档同步不改变运行代码、测试剧情、现有存档、卡牌数值、资源或已批准美术。

## 四、仍待主创决定的接口

以下是尚未定义的内容，不影响本轮已确认条款生效：

1. **死亡解决的实现方式**：身体维护、衰老、意外、恢复及意识连续性如何处理；不据此恢复35岁程序。
2. **观察对象与知情范围**：观察员真实身份原则上保密已确定；被观察者是否知道有观察事项、是否可拒绝，公众知道多少IGA的工作机制，仍待确定。
3. **观察员的身体与能力**：是否有饥饿、疼痛、疲劳，是否可读心、调用记录、请求IGA服务；“不懂人心”不等于已经确认无常识或低智力。
4. **观察与帮助的边界**：观察员何时可以提供帮助，谁作决定，怎样处理当事人不同的要求；未定规则不能写成正式禁令。
5. **一年后的处理**：一年期满须携带数据返回月球已经确认；何时向社区告别、是否能够再来、记忆及既有关系如何延续仍未定。不自动附加死亡、格式化、永久断联或清除社区记忆。
6. **地区串联方式**：同一被观察者的生活关系如何抵达不同地区，是否有不同观察事项与叙事视角。
7. **旧主线的取舍**：十二卡、先知历史、教团、同盟及阿戈拉旧故事怎样进入新结构。
8. **起源与生命逻辑**：外来信息流、月球AI及自我维持旧背景是否沿用，如何与本轮服务及生活记录衔接。
9. **身份暴露与回收**：何种行为算暴露、怎样发现、回收如何执行、有无例外以及之后的处境；不得把“回收”直接解释为处死或清除人格。
10. **信息的用途和IGA的理解能力**：收集记录是为了进一步了解人类已确认；记录的格式、分析方式、IGA当前对人类理解到何种程度，以及如何运用所获认识，尚未确定。
11. **模仿与真实情感**：观察员表现出的热情、关心和悲伤，究竟是模仿、主观体验，还是二者无法简单区分，保持开放。主创提出“伪物比真物更卖力地表现为真物”的思考，但不将其写成已证实的世界规律或剧情结论。
12. **玩家何时得知真相**：已确定观察员知情、玩家开始时不知情；揭示节点、叙事视角、先前行为如何被重新理解等未定，不能提前把开场身份保密写成固定章节时序或预设反转结局。

## 五、原始决定与可选方案的边界

本轮已确认文本来自主创：

> “35岁死亡设定取消。”
>
> “iga的出现改造了人类生活，它解决了人类当今的所有重大矛盾。战争，饥饿，疾病，死亡。”
>
> “主角是iga派来观察人类的观察者”，事项为“随机抽取一个人跟随一年，记录他的生活”。
>
> “iga的设定改为服务于人，持续记录人的生活信息”，观察员“以一个合适融入当地社区的身体身份参与大家生活”；初始设定“天真，善良，热情，不懂人心”。
>
> “这些地区每个地区都讲一个故事，表达一种情绪。”
>
> “观察员原则上不能暴露自己身份，不然会被回收，观察期一年满后必须带着数据返回月球。”
>
> “这个借鉴章鱼辟，就像之前设定的，带回人类信息，了解人类。”
>
> “观察员只是模仿人，这其中是否诞生了真实的情感，我不知道，伪物会比真物表现的更加卖力，行为举止更加真实丰富，真物因为一开始就是真物，所以并不会在表现本身存在为真物上有任何兴趣。”
>
> “观察员知道但是玩家不知道。”
