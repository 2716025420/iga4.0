# IGA 正式剧情剧本编写范本（可直接转入游戏引擎版）

> **使用方式**：主创只需按本范本用纯文本 / Markdown 编写剧情（无需写代码或 JSON）。写完一幕或一章交回后，即可按字段直接导入游戏的 `PhaseTwoContent`（主线/支线全屏演出）、`CampusLife`（场景内 NPC 短对话）或 `DayCycle`（日程事件）。
> **世界观约束提醒**：以 [2026-11-14 世界观与全案重构设计书](2026-11-14-世界观与全案重构设计书.md) 与 [2026-10-28 黄秋枫序章剧情逻辑](2026-10-28-黄秋枫序章剧情逻辑.md) 为准。

## 一、剧本写作极简语法（6 条规则，3 分钟上手）

### 1. 每幕开头的「场景卡片」（元数据头）
每一段独立剧情用一个 `---` 块声明基础信息：

```yaml
---
剧情ID: ch1_01_bully_rescue        # 英文或拼音唯一标识（不确定可先留空由程序填）
类型: 主线剧情                      # 可选：主线剧情 / 场景NPC对话 / 支线事件 / 过场片段
所属章节: 序章                      # 序章 / 第一章 / 日常
幕名: 樱道解围                      # 会显示在顶部章节幕牌和《放映档案室》胶片目录中
触发地点: morning_road             # 触发方式：自动开场 / 图书馆点击黄秋枫 / 旧公园点击长椅 等
触发前置: 无                        # 例如：完成 ch1_01、卡组>=4张、时段=黄昏
时间推进: 第1天 07:45               # 结束后游戏时钟跳至几点（留空=不改时间）
默认背景: morning_road             # 见下方第四节 ID 速查表；若需新画背景写 [待画:描述]
默认BGM: bgm_campus_daily          # 见下方速查表
结束后动作: 进入下一幕 ch1_02       # 可选：回社团教室 / 留在本场景 / 进入战斗:enemy_id / 进下一幕
解锁标志: [prologue_met_qiufeng]   # 可选：剧情完结后记录的状态标记
结算奖励: 无                        # 可选：零用钱+100 / 物品:quest_sample / 解锁同伴:liu_yu_long / 星座:hero
---
```

### 2. 正文台词写法（核心只有 4 种行）

| 你要写的内容 | 规范写法 | 说明 |
| --- | --- | --- |
| **角色台词** | `角色名(表情, 站位): 台词内容` | 站位写 `左` 或 `右`（省略则沿用上次站位）；表情省略默认 `平静` |
| **旁白 / 内心** | `旁白: 叙述文字` 或 `叶舟(内心): 心里想的话` | `旁白` 不切换立绘高亮，纯文字呈现 |
| **演出指令** | `[指令名: 参数]` | 独占一行，控制换背景、双层过场、音效、切曲、镜头、震动、CG |
| **玩家选项** | `> 选项1: 选项文字 => 效果` | 支持分支回应台词或只加好感/记标志位 |

### 3. 常用演出指令（全部可选，需要时才写）

```text
[背景: library]                  # 切换背景（若需新图写 [背景待画: 夕阳下的旧贩卖机角落]）
[过场: old_park_dusk]            # 切入双层视差过场动画（离开时写 [过场: 关闭]）
[BGM: bgm_dusk_memory]           # 切换背景音乐（写 [BGM: 静音] 可突然收声制造压迫感）
[SFX: hit_overclock]             # 播放一次性音效（见速查表；新音效写 [SFX待补: 汽水开罐声]）
[立绘退场: 右]                    # 让左侧/右侧/全部立绘退场
[立绘特殊: 黄秋枫=damaged_fiber]  # 切换特殊剧情立绘（如光纤受损、结晶休眠、反叛者摘面具）
[镜头: 震动] / [黑屏过渡: 1秒]    # 演出标注，导入时转成 Godot Tween 演出
[备注: 这里节奏停顿半拍，突出反差] # 给程序/美术的导演备注，不会显示在游戏里
```

### 4. 分支选项写法（两种都支持）

**写法 A：轻分支（选完给 1~2 句专属回应 + 加好感，再汇回主线）**
```text
? 玩家选择:
  - 选项A: "把联系编号记下来吧，以后有事随时找我。" [好感: 杨子英+5] [标志: chose_warm]
    黄秋枫(害羞, 右): 嗯……我会认真存好的。
  - 选项B: "校园里的护盾规矩很严，别随便把初始卡让出去。" [好感: 杨子英+10]
    黄秋枫(平静, 右): 原来如此，谢谢你的提醒。
```

**写法 B：仅加好感直接续接下一句（与现行引擎 100% 原生兼容）**
```text
? 玩家选择:
  - "把联系编号记下来吧。" [好感: 杨子英+5]
  - "先熟悉一下校园规矩吧。" [好感: 杨子英+10]
```

### 示范 1：主线剧情幕（含序章口述逻辑、演出指令、分支、战斗衔接）

[黑屏过渡: 0.8秒]
[备注: 清晨阳光穿过樱道，节奏轻松，随后突然收紧]

[SFX: ui_click]
[备注: 远处传来起哄声与推搡声]

叶舟(厌恶, 左): ……啧。

[BGM: 静音]
旁白: 我本来只是下意识皱了下眉，并不打算多管闲事。可刚走出三步，身后的笑闹声却突然停了。

[备注: 小混混勾住叶舟脖子，眼神发狠地暗示附和]

? 玩家选择:
  - "……嗯，是的。" [标志: bully_complied_quiet]
    旁白: 话一出口，我只觉得耳根发烫。
  - "对、对，我们在排练。" [标志: bully_complied_nervous]
    旁白: 连声音都在发抖，糟糕透了。

黄秋枫(微笑, 右): 原来如此，大家关系真好呀。不过不好意思，我刚好有事想找这位同学，能先借他一会儿吗？

[立绘退场: 右]
旁白: 几个高年级生顺着台阶打着哈哈散开了。转角很快安静下来，只剩下我和她。

黄秋枫(担忧, 右): 刚才没有受伤吧？如果害怕的话，可以在这里先坐一会儿。
叶舟(害羞, 左): 没、没事！谢谢你……我还有事，先走了！

[立绘退场: 左]
[SFX: page_flip]

## 四、给主创的写作小建议（避免后期返工）

1. **每句台词控制在 18～55 字（约 1～2 行）**：现行对话框（`1415×155px`，34px 字号）两行以内阅读最舒服，长段内心独白拆成 2～3 句更有电影停顿感。
2. **先写好文字与情绪，美术/音效留占位即可**：遇到当前还没有的背景、CG 或音效，直接写 `[背景待画: 运动会400米终点跑道]`，我们汇总时自动生成精准缺口清单，绝不卡住你写剧本的节奏。
3. **保存位置建议**：你写好的正式剧本直接放进 `docs/story/scripts/`（例如 `00_序章.md`、`01_第一章_阿瑞忒.md`、`02_校园日常NPC对白.md`），写完任意一幕发我即可直接接入游戏并做真机测试！
