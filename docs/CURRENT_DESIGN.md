> **基准索引**：世界观与五章大纲以 [世界观与全案重构设计书](story/2026-11-14-世界观与全案重构设计书.md) 为最高优先级，序章与第一章落地细节见 [序章与第一章聚焦重构与清理方案](story/2026-11-16-序章与第一章聚焦重构与清理方案.md)；工程交接现状见 [HANDOFF.md](../HANDOFF.md)。

## 1. 核心世界观与系统设定边界

- **世界观基线**：围绕“红月计算中心下的 IGA 社会 + 混入人类的无主观情感高拟真伪人 + 反叛组织（灰区同盟） + 红月圣堂教会”展开，早期「35 岁生命终点 / 观察员一年任务 / 熹微之光学园」已彻底废除，不得在文案或系统逻辑中恢复。
- **战斗世界观统一**：校内日常围绕战术刻印与**非致命终端护盾裁决**展开；夜间封锁与灰区冲突解除安全限幅进入**红月超限战（Overclock）**。已废弃早期叙事中的“学生智能终端”桌面/手册设定。
- **十二星座母卡（Zodiac Mother-Cards）**：永久剧情收藏品，收录于《十二星座图鉴》，**绝不加入普通商店交易或随机掉落**；可在图鉴中切换激活 1 枚作为战场共鸣核心被动。
- **社团中枢（Home）、实体商店与工坊规则**：社团教室「records」槽位升级为《**放映档案室**》（四合一：委托与成就 11 枚印章领奖、故事胶片含 8 篇风物纪要、同学拍立得羁绊档、社团收纳）；购买行动卡、强化素材与补给在实体商店办理，阿瑞忒校园商店随主线进度分三档（`6 → 11 → 16` 款）供应行动卡，支持“全部 / 仅未拥有”筛选，保留防重放、余量校验与特殊卡拦截；工坊行动卡强化与同伴交流均为 0 活动点消耗。
- **出战卡组约束**：最多保存 3 套独立 5 卡方案，应用状态唯一；出战配置在装备层强制至少保留 1 张 `ATTACK` 卡，未保存草稿不覆盖真实出战卡组；阿瑞忒校园循环交替图书馆 / 商店 / 天台 / 海滨 / 旧公园，并在体育馆「阿瑞忒巡回代表选拔赛」（3 轮递增挑战）赢取代表通行章后衔接诺莫斯第二章。

## 2. 美术流程与屏幕适配约定

- **画布与多比例适配**：所有界面以 `1920×1080` 为设计坐标系，支持 `1600×900`（16:9）及 `1600×720`（20:9 宽屏，使用 `2340×1080` 宽延伸底图或居中舞台填充，零黑边且热点与背景同坐标系配准）。
- **整页概念母图 → 分层还原流程**：新 Home、地区地图及剧情功能场景须先确立含完整 UI、人物占位、按钮层级与信息区的 `1920×1080` 整页概念母图，再拆分透明前景/底板，在 Godot 内用实时文字、控件与输入热区还原，严禁仅铺纯房间背景再临时拼装原生按钮或将文字烘焙进图片。
- **四大学院与两剧情区识别**：诺莫斯（巨树小酒馆 Home，「第二章待开」）、阿瑞忒（社团教室 Home + 含旧公园 8 处功能场景的昼夜手绘校园地图与海滩）、阿戈拉（强制劳动宿舍 Home）、忒克捏（黑白研究室 Home）；失败者同盟与 IGA 信仰教团无 Home，仅作含多难度副本、商店与功能区的剧情地区（第 2–5 章目前保持占位框架，不擅自定稿正式剧本）。
- **视觉去噪与统一基线**：
  - 现有社团教室、放映档案室、卡匣工坊与校园室内 UI 维持已落地风格与交互结构；**地图体系按 v12 规范精简与动态升级**：
    - 阿瑞忒校园地图整合为 **7 处核心地标**（天台 / 宿舍 / 社团 / 图书馆 / 商店 / 体育馆 / 沿海公路），**《旧公园》与《阿瑞忒海滩》已并入《沿海公路》内部双入口分支**；地图含脉冲定位环、浮漂扫光剧情标、名牌联动缩放及昼夜图平滑切换；
    - 六地区巡回总图已精简为 **每区唯一 1 张统一卡片 `RegionCard_<id>`**，配套动态流动虚线巡回航线与底部地区情报预览，**底图继续沿用当前审定保留的大世界地图背景 [world.png](../assets/ui/scene_reset/maps/world.png) / [world_wide.png](../assets/ui/scene_reset/maps/world_wide.png)**；
    - 近期旧归档压缩包及无引用旧占位素材已清理，其余美术批次暂停按旧提示词生图，后续以主创重新定稿的风格标准为准。
  - 可操作控件保留纯鼠标悬停／按下反馈、键盘导航（无额外焦点外描边 `SchoolObjectUI.borderless()`）及 `reduced_motion` 降动态支持；
  - 透明遮罩仅调 Alpha 避免叠加出第二圈暗边；不恢复已撤回的通用悬停说明弹窗。

## 3. 战斗画面与操作基准（v8 定型）

- **四段式分层架构**：顶栏（`TopInfo` `0..76`）→ 上方 HUD 信息与状态带（`ArenaHUDBand` `78..206`）→ 统一足底站台地平线（`CombatStagePlatformArt` `566..658`，角色脚底对齐 `y = 634`）→ 底部行动手册手牌区（`654..1080`）。
- **定尺站位与头顶双层秩序**：
  - 同屏敌人上限 **3 名**，1/2/3 敌时维持恒定 `332×572` 槽位与 `290×400` 包围盒，不再随人数缩放；
  - 叶舟（`center_x = 456`）与所有敌兵头顶遵循**「上：信息显示栏（`PlayerIdentity` / `IdentityPaper`）→ 紧贴头顶：图标+数字状态行（`PlayerStatusIcons` / `EnemyStatusIcons`）」**；
  - 同伴固定左后站位（`comp_center_x = 152`，略错后），头上无任何信息栏或状态栏。
- **交互**：桌面端支持点击或数字键 `1–5` 出牌、`Tab` 切目标、`Space`/`Enter` 结束回合、`H` 开关战报；触控模式支持预选抬起与上滑确认；逃跑立即判负并清除本场战斗快照。
