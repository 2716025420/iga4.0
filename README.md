# Inorganic General Alien（IGA）· just-life

以熹微之光学园为故事起点的 Godot 4.7 卡牌与对白游戏。IGA 是由外来信息流同化月球 AI 算力中心后形成的独立意志，将社会改造视为互惠：它普及机器人服务、社会保障、医疗与教育，满足人类对幸福和规避痛苦的祈愿，并从人类生活产生的新信息中维持自身。人类大多俊美、年轻而有活力，在少数约定规则之外享有广泛自由；大学筛选、普通人35岁生命终点，以及衰退者被清除并上传自身信息，共同构成社会制度。群体性不满容易发展为暴动。故事发生在 IGA 出现约35年后。设定见 [现行设定入口](docs/CURRENT_DESIGN.md) 与主创工作区的 [完整设定](docs/story/IGA-世界观设定.md)。

当前美术采用水彩动漫与场景物件设计；叶舟、杨子英、柳宇龙、姜梓保留姓名，四人立绘将重新设计。已有章节和日常文本用于流程验证，正式剧本与新人物外观仍待完善。本机目录 `fun-in-end-world`、仓库名 `just-life` 为既有工程标识。

## 运行

使用 Godot 4.7 打开 `project.godot`，等待资源导入后运行项目。项目包含正式运行素材、中文字体、场景和脚本，使用1920×1080设计区及1600×900默认窗口。

## 当前版本

- 连续对白/战斗主线原型，四位角色的六情绪半身素材。
- 首页提供同学交流、卡牌整理、校园记录、校园地图与休息；关键主线按日期自动到指定场景触发，正式日期待剧本填写。
- 游戏从10月1日开始，显示月日、星期与早晨/下午/夜晚；每时段暂设 3 次活动，休息按早晨→下午→夜晚→次日早晨推进，Home 四层素材与校园地图自动切换。
- 独立地区总图与地点地图连接校园、反抗联盟及教会圣地；校园初始开放，其余地区由专用剧情标记解锁。校园保留首轮简化原图中的朱砂「放学环线」和靛蓝「星轨课表」，信息栏无大块底板，另两个地区使用几何布局与各自 Home。
- 体育馆提供三档模拟训练、互斥分支、材料奖励与路线暂停恢复；战斗中的逃跑立即判负并清除本场快照。
- 出战卡组至少一张攻击卡：默认方案1只装备一张攻击卡，卸载、替换及方案保存/应用在装备层保证此规则。
- 校园自由探索覆盖图书馆、自习室、商店/仓库、天台、宿舍与体育馆；通过独立地图页面选择地点，在体育馆内进入训练。自由探索、训练与主线进度独立；商店当前不提供购买。
- Home 女主具备呼吸、眨眼与局部形变，支持减少动态。
- 首页完整后景、独立透明前景与真实UI，保持清晰纸绘结构。
- 新 Title 校园窗景、独立透明桌面前景和编号式纸面菜单。
- 继续游戏、新游戏覆盖确认、自动存档与有效备份恢复；音量、全屏设置持久化。
- 新战斗纸面布局、独立回合记录窗口和结算输入锁定；六张卡牌共用512×512透明素材。
- 校园记录第四页仓库：按类别筛选、搜索、详情、数量和任务奖励去重。

## 仓库范围

此仓库保存可运行工程、正式素材、插件源码、维护工具和文本开发记录。`.godot`缓存、构建输出、机器配置、二进制旧归档、生成母图与截图保留在开发机本地，不纳入Git。旧规范原文归入 `docs/history/`；已替换素材和一次性制作脚本归入本机 `archive/`，原路径、分类、SHA256 与恢复说明保存在对应审核记录中。历史工具不能直接重放，执行验收前需核对当前节点结构与现场状态。

Godot MCP验证工具目前依赖开发机的本地MCP环境；运行游戏本身不需要Node依赖或网络连接。
