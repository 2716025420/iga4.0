本目录放置 `AudioManager` 按场景情境自动加载与交叉淡入淡出的 7 首背景音乐（当前已实装免费商用授权 `.mp3` 音源；亦支持同 stem 的 `.ogg` / `.wav` 按 `.ogg` -> `.mp3` -> `.wav` 顺序加载）：

- `bgm_title_serene.mp3` — 标题页、加载过渡与设置电台（自动循环）
- `bgm_campus_daily.mp3` — 社团教室 Home、校园地图、图书馆、天台、宿舍、沿海公路、海滩与工坊图鉴（自动循环）
- `bgm_shop_breeze.mp3` — 校园商店与商店柜台分栏界面（自动循环）
- `bgm_dusk_memory.mp3` — 放学黄昏、旧公园长椅约会、黄秋枫结晶独白、红月夜日常与放映档案回忆（自动循环）
- `bgm_duel_practice.mp3` — 柳宇龙校门教学切磋、体育馆模拟训练与阿瑞忒代表选拔赛（自动循环）
- `bgm_redmoon_overclock.mp3` — 红月门禁封锁、灰区拦截机与猎杀终端 BOSS 超限战（自动循环）
- `bgm_victory_stinger.mp3` — 战斗胜利结算短奏（单次播放，不循环）

> 曲目版权归属与 CC-BY 4.0 署名要求见 `assets/audio/CREDITS.txt`；重新抓取或恢复下载见 `tools/audio/fetch_free_audio.py`。
