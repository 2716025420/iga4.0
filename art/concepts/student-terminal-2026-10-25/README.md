# 智能终端与到店柜台 · 概念来源

`overview.png` 是主创本轮指定的唯一终端视觉基准。其它原始PNG只作为屏内功能设计来源，其中不同的平板边框/镜头/透视不作为运行时机身。`TerminalProjection`统一裁切和映射屏内结构；所有终端页面使用概览的同一机身、外部背景与光照。

屏幕底色和共享导航也固定：`screen-paper.json`记录空屏提取来源，其源图里的设备外框不参与绘制。各页结构图仅按UI底板轮廓遮罩叠加，避免把整块不同底色贴进共用屏幕后产生拼接边界。

先制作 `art/layouts/student-terminal-2026-10-25/` 的七张SVG功能布局，再使用内置 `image_gen` 生成完整母图。`manifest.json`保留原始提示；`layers.json`记录从母图去掉文字、数据、图标和内容后保留的结构层。实时内容、交互和可变状态由Godot实现。原始生成文字与示例数值不代替游戏数据；比如卡牌正式显示名、能力数值和收藏状态均以现行服务为准。

商店是独立地点柜台，`shop.png`不属于终端应用。母图展示共同测试柜台的视觉，六地区的店主、独有货源和正式内装仍待后续完善。星座名称对应为可调整提案，人物外观、持卡人和获取剧情未定稿。截图和失败候选保留在忽略的本机测试目录，不进入项目素材目录。
